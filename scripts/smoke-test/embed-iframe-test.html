Embed call — local smoke test

Setup

  1. Log in at http://localhost:3000 and open an agent.
  2. Enable Embed Button (leave allowed domains empty for local testing).
  3. Copy the agent UUID and paste it below.
  4. Ensure dev stack is running (./start.sh start dev).

Option A — iframe (same as popup)

Opens /embed/call?agentId=… on the frontend. Microphone permission is required.

Option B — floating call button script

Uses the production embed script from your local frontend. Click the floating button in the corner after loading.
